Project Description
The Bakery Website is a small business website for showcasing cakes and
pastries. Customers can view bakery products, choose the quantity they
want, and use a simple pre-order form.

The website is designed with a soft, pastel, bakery-themed appearance
and an easy-to-use layout.
Features
- Product cards: Display each product's image, name, and price.
- Quantity selector: Increase or decrease the quantity with +
  and − buttons.
- Live price calculation: Update the total price based on the
  selected quantity and product price.
- Pre-order form: Provide a simple form for entering pre-order
  details, including the selected quantity.
- Bakery-themed design: Use a pastel colour palette, rounded
  cards, and soft shadows.
- Input constraints: Keep quantity values within valid limits.
Technologies Used
- HTML --- Structures the webpage, product cards, quantity
  controls, and pre-order form.
- CSS --- Styles the page with a pastel bakery theme, card grid,
  rounded corners, and soft shadows.
- JavaScript --- Handles quantity increment/decrement, input
  validation, and live price calculations.
Project Requirements
HTML
- Product cards containing an image, product name, and price.
- A pre-order form with a quantity selector.
CSS
- Pastel, bakery-themed colour palette.
- Product cards arranged in a grid.
- Rounded cards with soft shadows.
- Styled quantity input and + / − buttons.
JavaScript
- Increase and decrease the selected quantity using the + and −
  buttons.
- Calculate the total price using:
  Total Price = Quantity × Unit Price
- Update the displayed total whenever the quantity changes.
- Validate quantity input so that invalid values are not accepted.
How to Run the Project
1. Clone or download this repository to your computer.
2. Open the project folder.
3. Locate the main HTML file (usually index.html).
4. Open index.html in a web browser to view the website.
5. Try the + and − quantity buttons and check that the total price
   updates correctly.
6. Review the pre-order form and test its input constraints.
If the project uses separate HTML, CSS, and JavaScript files, keep them
in the project folder and preserve the file paths referenced by the HTML
file.
How to Review the Project
- Check that each product card shows its image, name, and price.
- Increase and decrease a product's quantity and verify that the total
  price changes correctly.
- Check that quantity values remain valid.
- Review the pre-order form and the overall layout on the page.
Learning Outcomes
This project provides practice with:
- Building webpage structure with HTML.
- Styling layouts and product cards with CSS.
- Implementing increment/decrement logic in JavaScript.
- Updating prices through live multiplication calculations.
- Validating user input and handling quantity constraints.
- Combining HTML, CSS, and JavaScript into a small interactive
  website.
